Qstar-LLM

Zero-dependency, deterministic AI inference engine built on discrete lattice geometry.

Overview

Qstar-LLM uses Q32.32 fixed-point arithmetic for bit-exact reproducibility across all platforms — no floating-point drift, no GPU required. The entire engine runs in WASM inside this single HTML file.

584 tests across 23 src + 13 prototype modules. 38 tools. 0 external dependencies.

Key Features

• Speculative draft mode (Qstar generates, Ollama verifies)

• Concurrent HTTP server (thread-per-connection, 64 simultaneous)

• Streaming responses (chunked NDJSON)

• Competitive benchmark suite (Qstar vs Ollama)

• 29 topic category routes for domain-specific responses

• Trigram model with anti-repetition window

• Naturalness engine with formal-to-casual conversion

• Semantic retrieval with query keyword expansion

• 3-layer cognitive memory (working, episodic, callbacks)

• BPE tokenizer with Ramsey vocabulary scaling

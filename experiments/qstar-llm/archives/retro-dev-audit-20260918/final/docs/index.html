Qstar

Lattice-native autonomous reasoning & computing engine. Pure Zig, zero dependencies, integer-only arithmetic. 421 E0 nodes × 7 channels.

Zig 0.13 Q32.32 Fixed-Point 12 Transport Modes Ollama Compatible OpenAI Compatible

Features

Lattice Inference

421 E0 nodes with 7 octonionic reasoning channels. Fibonacci projection, Möbius reflection, refractory inhibition, and self-assembly Monte Carlo relaxation.

Ollama + OpenAI API

Drop-in compatible HTTP server on port 11435. Supports /api/generate, /api/chat, /v1/chat/completions, streaming, tool calls, and embeddings.

Virtual Mesh Network

Headless over-the-air mesh with 12 virtual transport modes: p2p, wifi, qr, video, audio, stega, quine, polyglot, paper, cassette, optar, paperback.

Collapse Recovery

Civilization collapse simulation with automatic transport degradation chain. Falls back from digital to analog modes (paper, cassette, quine) when infrastructure fails.

Self-Training Pipeline

Trains from Ollama, Wikipedia, and document ingestion. Knowledge graph extraction, continual learning heartbeat, and OpenAI reinforcement.

Quine Edition

Self-referential HTML with embedded lattice + corpus. Deploy to GitHub Pages for a fully self-contained interactive web experience.

Quick Start

# Build zig build # Start Ollama-compatible server ./zig-out/bin/qstar serve # Run a prompt ./zig-out/bin/qstar run "What is the speed of light?" # Interactive chat ./zig-out/bin/qstar chat # Mesh commands ./zig-out/bin/qstar mesh start 9000 ./zig-out/bin/qstar mesh status ./zig-out/bin/qstar transport list # Collapse simulation ./zig-out/bin/qstar collapse simulate ./zig-out/bin/qstar collapse status

Transport Modes

P2P

Direct encrypted peer-to-peer packets using X25519 key exchange and ChaCha20Poly1305.

WiFi CSI

Data embedded in WiFi channel state information frames (ADR-018 binary format).

QR Portal

Data encoded as QR code images with recursive nesting for large payloads.

Steganography

LSB embedding in PNG images with AES-GCM encryption.

Quine

Self-referential HTML with base64-embedded payload. The carrier IS the data.

Paper

Printed text and QR codes on physical paper for offline transport.

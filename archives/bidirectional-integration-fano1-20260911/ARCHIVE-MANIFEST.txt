ISSUES FOUND AND FIXED
  1. MISSING LICENSE HEADER: src/fano_tensor.zig had no CC BY-NC-SA 4.0
     license header → added as first line.

  2. FROMRATIO ROUNDING BUG: Q128.fromRatio(0, 1) returned 1 instead
     of 0. The condition `remainder == half_den and abs_den > 0`
     incorrectly rounded up when both remainder and half_den were 0
     (denominator = 1). Fixed by changing condition to
     `remainder == half_den and remainder != 0`. Added 3 new tests
     covering fromRatio(0, 1), fromRatio(0, 7), and fromRatio(0, -3).

  3. WASM BUILD API: wasm/build.zig used resolveTargetArgs (removed
     in Zig 0.13) → replaced with resolveTargetQuery. Removed unused
     proof_mod module constant.

  4. WASM I256 LIMITATION: wasm_main.zig imported src/proof_core.zig
     which uses i256 arithmetic (compiler-rt not available in wasm32-
     wasi with Zig 0.13). Rewrote to export 10 integer-only proof
     checks that run in any WASM runtime.

  5. POLYGLOT C ABI: polyglot_codon_hook.zig passed [3]u8 array
     parameters in export fn (not allowed in C calling convention)
     → changed to pointer parameters.

  6. NEURALEAK TEST: neuraleak_qwen_hook.zig test expected
     direct_experience == 1 for a response without "experience" or
     "perceive" keywords → adjusted test fixture.

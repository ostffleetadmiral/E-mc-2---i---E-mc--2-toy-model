## 2. Arithmetic Semantics

**Type:** `q128 = U256 = struct { hi: u128, lo: u128 }` — 256-bit two's-complement.

**Multiply:** Exact 512-bit product via 64-bit-limb schoolbook, then round-to-nearest-even (RNE) shift by 128. Error bound: `|x*y - fl(x*y)| ≤ 2⁻¹²⁹` (half ulp). Overflow saturates to `Q128_MAX` / `Q128_MIN` with overflow flag.

**Division:** Truncating (floor toward zero). `from_ratio(num, den)` uses round-half-away-from-zero (matches Python reference sim).

**Square root:** Newton's method, 256 iterations max, on the raw 256-bit mantissa.

**Inner product:** Exact 512-bit accumulation: `⟨(a,b),(c,d)⟩ = a*c + b*d` computed without intermediate rounding.

**Rotation:** `rot90(x, y) = (-y, x)` — exact negation and swap, no rounding. Period 4.

### Key Properties (Module 1 proofs)
- **Floor invariance:** `|x - y| ≥ 2⁻¹²⁸` for distinct x, y
- **Bounded error:** `ε ≤ 2⁻¹²⁹` per multiply
- **Orthogonality preservation:** `Re(⟨u, v⟩) = 0` exactly after rot90

### Divergence note
The Python reference sim uses round-half-away for multiply; the C and Zig engines use RNE. All documented test outputs are unaffected (tested values are exact under both modes).

## 5. Fano 15³ Tensor

3D Fano tensor: 15×15×15 grid representing ONE qubit.

- **Central e0** at (8,8,8) — observer pivot
- **6 arms** (e1–e7) radiate along ±x, ±y, ±z
- **421 e0 nodes** surrounded by 6 directional arm structures
- **Layer mirror symmetry:** layer k ↔ layer 16-k
- **Layer pivot:** `i = ek` = center column value at row 7
- **Generation rule:** `c = (8 - L) mod 8` for L ≤ 8; `c = (L - 8) mod 8` for L ≥ 9; rows/cols symmetric around index 7
- Encased in 16³ e9 9D quantum foam shell; 2+ shells compound to 10D

## 7. Holographic Compression (513³ → 16³)

**Fold:** `N³ grid → 16³ core + winding vector + defect charge w`
**Reconstruct:** `(core, w) → N³ grid` — O(1) per cell, fixed boundary operator independent of N
**Ratio:** 32,908:1 (513³ nodes / 16³ core); 19,173,961:1 (512³ → 7-node e0 pivot)

### Mechanism
- Core = central 16³ block
- Winding vector = per-cell exact residual (defect charge), stored as Q128.128 values
- Odd-perimeter defect charge `w ≠ 0` for odd N (513 = 512+1); `w = 0` for even N
- Family states (FANO-1-representable): every non-core cell is an exact pivot quarter-turn of its even-floor neighbor → bit-exact reconstruction
- Arbitrary grids: residual mode with graceful degradation (~1:1 floor)

### On-disk format
```
FHOLO1 header (64 bytes): magic, version, N, ladder, levels, mode,
  winding_len, residual_count, perimeter_count, defect, core_hash
Core: 16³ × 64 bytes (complex Q128.128)
Winding: RLE-encoded (count, value) pairs
Residuals: full values for non-family cells (scan order)
```

**Implementation:** `zig/holo.zig` — fold, unfold, serialize, deserialize. CLI: `zig build codec`. Tests: round-trip bit-exactness at N ∈ {17, 33, 65, 129, 257, 513}.
